# Knowledge for the Chakshu room

Policies of **Chakshu Demo Bank, a fictional bank**, plus a summary of public US guidance.
They are attached to the `#aml-alerts` room as room documents, so every agent reads the
same rulebook and cites it by ID (for example "per AML-03").

| ID | Document |
|---|---|
| AML-01 | Alert triage and escalation, and the decision format |
| AML-02 | SAR decision, deadline and confidentiality |
| AML-03 | Account takeover and fraud referral |
| AML-04 | Customer due diligence and expected activity |
| AML-05 | Sanctions and watchlist screening |
| AML-06 | Money mule and network indicators |
| REF-01 | Public US regulatory references, summarised |

These files are the source. After editing one, rebuild the room template:
`python scripts/build_room_template.py`.

Not legal or compliance advice.
